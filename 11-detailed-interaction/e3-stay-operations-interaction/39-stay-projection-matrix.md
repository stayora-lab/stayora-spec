# Stay Projection Matrix

| Canonical stage/observation | Guest | Host | Butler | BQL | Admin |
|---|---|---|---|---|---|
| SCHEDULED | scoped Stay/dates | responsibility/preparation | assigned upcoming | arrival scope | exception only |
| preparation milestone | relevant readiness | coordinate | report/see assignment | need-to-know | governed issue |
| Ready milestone | arrival confidence only | readiness | readiness | readiness if scope | exception |
| arrival observed | access/help | awareness | awareness | awareness | exception |
| CHECKED_IN | operational Stay | operational responsibility | assigned support | active Stay | exception |
| Incident present | impact/help | authorized evaluation | evidence/escalation | destination issue | governance |
| departure observed | departure info | awareness | awareness | awareness | exception |
| CHECKED_OUT | outcome | completion evaluation | handoff | scope outcome | exception |
| completion pending | scoped outcome | blockers/evaluation | handoff | scope | governance |
| COMPLETED | post-stay truth | completion | handoff | outcome | audit |
| DID_NOT_OCCUR | permitted outcome | decision/attention | assignment outcome | scope | governance |
| manual exception | safe follow-up | responsibility | result | scope | assigned case |

Milestones/observations are not automatically lifecycle states.
