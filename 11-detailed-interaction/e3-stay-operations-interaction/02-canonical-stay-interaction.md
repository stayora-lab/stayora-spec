# Canonical Stay Interaction

`Accommodation Basis → SCHEDULED → preparation/Ready milestone → arrival observation → authorized Check-in → CHECKED_IN → operational support/Incident → authorized Checkout → CHECKED_OUT → completion evaluation → COMPLETED where canonical`.

`SCHEDULED → DID_NOT_OCCUR` is a separate canonical branch. Booking and Stay remain distinct; External Accommodation may support Stay without a Stayora Booking. No IN_STAY or ARRIVED state is invented.
