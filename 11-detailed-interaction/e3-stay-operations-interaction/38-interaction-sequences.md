# Interaction Sequence Findings

A. Upcoming Stay becomes relevant: legitimate basis → canonical Stay/SCHEDULED where defined → scoped Host/Guest/Butler/BQL projections.

B. Butler views assigned Stay: Today → Assignment → Stay detail → current truth/scope/authority.

C. Preparation/readiness: authorized observer → evidence/milestone → canonical projection/attention.

D. Guest arrival: expected/observed arrival → scoped access/help → no Check-in.

E. Check-in: current truth → capacity/Assignment → authority/preconditions → revalidation → action → canonical outcome/projections.

F–G. Blocked/duplicate/concurrent Check-in: preserve truth, no duplicate, route conflict/manual.

H–K. In-Stay help, Incident, escalation and B5 Inventory handoff preserve evidence/authority boundaries.

L–N. Departure, Checkout and blocked/concurrent Checkout follow the same grammar; Checkout ≠ Completion.

O–Q. Completion evaluation, COMPLETED and DID_NOT_OCCUR stop at canonical conditions/authority.

R–S. External-based Stay converges operationally; manual exception records responsibility and result.
