## Canonical flow

`Accommodation Basis → Stay SCHEDULED → preparation milestone → arrival observation → authorized Check-in → CHECKED_IN → operational period/Incident → authorized Checkout → CHECKED_OUT → completion evaluation → COMPLETED where canonical`.

`SCHEDULED → DID_NOT_OCCUR` remains a separate canonical branch. Preparation, Ready and observations are not invented Stay lifecycle states.
