# Error / Recovery Matrix

| Condition | Example | Recovery |
|---|---|---|
| validation failure | wrong Stay/resource | correct scope; no mutation |
| no authority | Butler Check-in without grant | explain category; route responsible authority |
| wrong Assignment | Stay outside Butler scope | select legitimate Assignment or handoff |
| wrong resource | wrong Unit | show current scope; no action |
| stale Stay | another actor checked in/out | revalidate; show current truth |
| already checked in/out | duplicate action | no duplicate; current outcome |
| conflict | accommodation/Incident issue | preserve evidence; authorized evaluation |
| technical failure | action result unclear | recheck safely; no false success |
| unknown authoritative outcome | Check-in/Checkout unknown | reconcile; no duplicate |
| credential/access issue | QR/privacy boundary | scoped support/manual path |
| manual assistance | policy edge | record responsibility/result |
