# Cross-Context Handoff

| Handoff | Canonical object | Receiving responsibility | Authority preserved |
|---|---|---|---|
| Sale Request → Host | Request | Host Request decision | Sale cannot accept |
| Host Booking → Guest | Booking/Stay basis | Guest Stay Access | Guest gets scoped access |
| Host → Butler | Stay/Assignment | assigned operations | Assignment/action grant |
| Butler Incident → Host/Inventory | Incident/evidence | responsible authority | Butler does not mutate Inventory |
| External Accommodation → Stay/Ops | External Accommodation fact | Host/Operations/Guest | no Stayora Booking required |
| BQL issue → responsible context | Incident/Stay/service | Host/Admin/Butler as scoped | BQL scope preserved |
| Admin reconciliation → origin | corrected/conflicted object | originating context | Admin action attributable |

Handoff transfers responsibility/attention, not authority or ownership.
