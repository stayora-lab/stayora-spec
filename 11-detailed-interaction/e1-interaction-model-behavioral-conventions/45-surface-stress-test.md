# Surface Stress Test

| Surface | Projection of common grammar | Distinct constraint |
|---|---|---|
| Public | read/intent → scoped Request | public truth only; no private authority |
| Guest | scoped Stay → access/operations | account optional; credential not authority |
| Host | consequential decision/Inventory/Money | authority and revalidation heavy |
| Sale | discovery/option/Request/outcome | no Booking/Inventory authority |
| Butler | field operational recording/action | Assignment and shallow recovery |
| BQL | destination operational awareness | function scope; no super-admin |
| Admin | governance/manual/reconciliation | attributable staff function; no impersonation |

The model is shared; responsibilities and data scope are not made identical.
