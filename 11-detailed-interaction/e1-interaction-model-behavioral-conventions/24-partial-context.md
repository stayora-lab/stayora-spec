# Partial Context

- NO RELATIONSHIP: context is not activated for that relationship.
- NO SCOPE: object exists but is outside current resource scope.
- NO AUTHORITY: visibility may remain, action cannot proceed.
- PENDING RELATIONSHIP / ELIGIBILITY: outcome is incomplete.
- UNASSIGNED: Butler/operational context lacks Assignment.
- UNPUBLISHED: Property representation is not public.
- NO DATA: valid scope with no objects.
- OUT OF SCOPE: capability intentionally outside V0.

These are behaviorally distinct and must not be flattened into one empty screen.
