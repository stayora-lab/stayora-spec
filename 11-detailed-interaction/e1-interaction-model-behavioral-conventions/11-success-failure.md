# Success and Failure Behavior

**Success** establishes canonical truth where applicable, refreshes projections, exposes next legitimate action, creates handoff/attention when required and preserves provenance. A toast or local UI state is never the source of truth.

**Failure** distinguishes input/validation, no authority, policy/business rejection, current-truth conflict, technical failure, unknown outcome and manual intervention. Recovery must not encourage duplicate consequential mutation. Final copy is not specified.
