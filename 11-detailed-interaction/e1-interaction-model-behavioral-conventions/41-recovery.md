# Recovery

| Condition | Safe recovery |
|---|---|
| Validation failure | correct input; no domain mutation |
| Lost/stale truth | refresh/revalidate; show current known truth |
| Conflict | preserve evidence; route to authorized responsibility |
| Technical failure | retry only when safe; retain intent status |
| Unknown outcome | do not duplicate; reconcile/recheck |
| Lost authority | explain scope/authority category; switch only to legitimate context |
| Manual-assist required | record evidence/request and responsibility; await canonical result |

Recovery never turns an uncertain consequential action into an automatic duplicate.
