# C1–C4 Stress Test

| Outcome | Interaction convention | Boundary |
|---|---|---|
| Invitation | record invitation intent/provenance | invitation ≠ relationship |
| Claim | preserve evidence and unresolved claim | claim ≠ truth |
| Relationship pending | partial context/attention | relationship ≠ authority |
| Eligibility | pending/approved/rejected/revoked outcome | no universal onboarding state |
| Property representation | authoritative recording/correction | publication/Verification policy |
| Authority grant | acting capacity and provenance | grantor/scope TBD where open |
| Sale relationship | context/resource activation | attribution/economics TBD |
| Butler Assignment | assignment-scoped context | Assignment ≠ Authority |
| Revocation | attributable supersession/revocation | future access changes; policy boundary |
| Multi-capacity Identity | context switch | switch ≠ permission |
