# Confirmation and Consequence Preview

Explicit confirmation is justified only when an action has material financial, Inventory, external, Guest, delegation, authority or hard-to-reverse impact. A consequence preview should show only effects supported by canonical truth: accepting a Request may affect conditions/Inventory; an Owner Block may conflict; Checkout does not imply Inventory release; Incident escalation does not automatically create a Block; revocation may affect future access. Modal/drawer/form behavior is not defined.
