# Acting Capacity

For an Identity holding Owner, Host, Sale, Co-host, Butler or other capacities, every consequential action carries an attributable acting capacity and authority source. The interaction must make clear which capacity is acting, which relationship/resource grants authority, and which object is affected.

Changing Host → Sale, Owner → Host or Butler → Host context changes projection and task set only. It never grants authority. If the capacity or grant is ambiguous, the action enters AUTHORITY UNKNOWN / REQUIRES RESOLUTION rather than guessing.
