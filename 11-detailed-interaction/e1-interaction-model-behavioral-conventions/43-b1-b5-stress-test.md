# B1–B5 Stress Test

| Journey | Common conventions | Policy/interaction boundary |
|---|---|---|
| B1 Sale Request → Host decision → Inventory/payment → Booking → Guest | Request intent, acting capacity, revalidation, consequential outcome, handoff | payment/confirmation economics remain policy blocker |
| B2 External Accommodation → Inventory/Stay → Ops/Guest | authoritative recording, provenance, conflict, manual reconciliation | no Stayora Booking; reconciliation depth TBD |
| B3 Guest Request → Host decision → confirmation → Stay | Request/Booking separation, revalidation, scoped Guest access | payment/confirmation branch not finalized |
| B4 Preparation → arrival → Check-in → Incident → Checkout → completion | operational recording, authorized action, evidence, handoff | Check-in/Checkout grants and privacy remain policy-bound |
| B5 evidence/Owner intent → Inventory action → derived projections | consequence preview, revalidation, derived Availability/Bookability | conflict resolution policy remains open |
