# Outcome Model

Interaction outcomes are not lifecycle states. Common categories are SUCCESS, REJECTED/NOT PERMITTED, VALIDATION FAILURE, CONFLICT, PROCESSING/PENDING, FAILED, UNKNOWN, PARTIAL/MANUAL FOLLOW-UP REQUIRED and CORRECTED/SUPERSEDED.

The projection must identify what is known, what changed, which responsibility now exists and what safe next action/handoff is available. Domain lifecycle state is only updated by canonical domain rules.
