# Direct vs Sale Convergence

| Difference allowed | Same canonical result |
|---|---|
| entry context | Request semantics |
| creator/acting capacity | Host authority model |
| attribution | Inventory truth |
| commercial projection | confirmation conditions |
| Guest communication path | Booking truth and later Stay handoff |

Direct Guest and Sale-assisted paths do not create different Booking objects or lifecycle. Offer/option remains distinct from Request in both.
