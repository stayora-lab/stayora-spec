# Consequence Preview

| Action | Canonical consequence to expose | Not assumed |
|---|---|---|
| Request submission | Request intent/creator/source and pending decision path | reservation/confirmation |
| Request acceptance | accepted Request; possible applicable commitment/conditions | immediate Booking |
| Request rejection | Request rejected and projections | Inventory mutation without basis |
| Inventory commitment | commitment/block basis and derived projection impact | duration/release/winner |
| Payment attempt | condition/attempt/outcome | retry/deadline/grace/refund |
| Booking confirmation | Booking truth, access/operations relevance | fake Stay transition |

Only known consequences are previewed.
