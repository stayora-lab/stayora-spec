# E2 Overview

E2 carries the same Request → Booking semantics through Sale-assisted and Direct Guest entry. It treats discovery as derived truth, Request as business intent awaiting authorized decision, acceptance as distinct from Booking confirmation, and Payment/Inventory conditions as explicit boundaries.
