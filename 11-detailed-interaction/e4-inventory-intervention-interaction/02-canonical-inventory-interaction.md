# Canonical Inventory Interaction

The interaction begins by showing current canonical truth and its provenance. The user then supplies an intent or evidence, acts in a real responsibility context, scopes the Unit × Time, and receives an authority-aware consequence preview. An authorized action is revalidated against current commitments, blocks and facts before it establishes or changes canonical Inventory truth.

`Inventory Fact/Evidence ≠ Inventory Decision`; `External Accommodation Fact ≠ Inventory Commitment`; `Inventory Commitment ≠ Availability`; `Availability ≠ Bookability`; `Searchability ≠ Availability`. The UI never turns a click into truth without authority and a canonical outcome.
