# Duplicate / Concurrent Intervention

A second action revalidates current truth and effective authority. If the first action already established truth, the second shows current outcome or conflict; it does not create duplicate blocks/commitments or silently overwrite history.

Unknown acknowledgement routes to safe reconciliation. E4 does not choose technical locking or idempotency design.
