# Attention

Attention is a projection for conflict, evidence awaiting evaluation, intervention requiring authority, external inconsistency, stale commitment, manual reconciliation or an affected accommodation. It is not a Task domain, priority algorithm or lifecycle state.

The attention item carries responsible context and next legitimate action where known; it does not imply a winner or resolution.
