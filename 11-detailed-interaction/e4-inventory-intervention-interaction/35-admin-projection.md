# Admin Projection

Admin receives scoped conflict, reconciliation and provenance context needed for governance. It may see enough to route responsibility and record an authorized manual outcome, subject to role/relationship/data access rules.

Admin projection is not a universal control plane, bulk CRUD surface or silent override.
