# Host Interaction

A Host may inspect and intervene only within effective Host capacity and Unit × Time scope. A Host relationship, listing responsibility or ability to accept a Request does not automatically grant every Inventory action.

Host actions revalidate current commitments, blocks, external facts and evidence. A blocked or conflicted action preserves the attempted intent and routes attention rather than silently changing Availability.
