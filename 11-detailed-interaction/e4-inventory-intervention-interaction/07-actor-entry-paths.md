# Actor Entry Paths

Entry paths may start from Host Inventory, an Owner perspective where explicitly authorized, Request/Booking context, External Accommodation context, Incident/evidence, or an Admin governance/reconciliation context. Butler and BQL enter through observation/evidence and responsible handoff.

Visibility, relationship, assignment and workspace do not imply Inventory Authority. Each entry path carries acting identity, capacity, relationship/resource scope, source context and authority posture into the same interaction contract.
