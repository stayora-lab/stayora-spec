# C1 / C2 compatibility

C3 preserves the chain:

`Identity → capacity/relationship → eligibility → resource scope → explicit authority → Working Context → bounded action`.

It does not modify C2 Host/Owner/Property semantics. A Sale relationship with a Property is not an Ownership or Hosting relationship. A Property creator, Owner or Host does not automatically become Sale; a Sale does not become Host/Co-host, Owner, Booking Authority or Inventory Authority. Working Context remains a projection, invitation/claim remains non-authoritative input, and there is no universal onboarding state.

The multi-capacity case uses separate capacities and authority bases on one Identity; audit attribution remains explicit.
