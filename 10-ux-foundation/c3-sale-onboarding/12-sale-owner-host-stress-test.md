# Sale + Owner / Host stress test

The same Identity may be Owner and Sale, Primary Host and Sale, or become Host after first acting as Sale. These relationships remain distinct and can change independently:

| Change | Sale relationship | Owner/Host authority |
|---|---|---|
| Owner also becomes Sale | Requires Sale eligibility/relationship | Ownership does not create Sale eligibility; Sale does not change ownership |
| Primary Host also becomes Sale | Requires independent Sale path | Hosting does not create Sale distribution authority |
| Sale later becomes Host | New Host relationship/authority decision | Existing Sale attribution/history remains separate |
| Host relationship ends | Sale may remain active for other scope | Host authority ends/re-evaluates per policy |
| Sale relationship ends | Host/Owner authority may remain | Future Sale actions stop; valid prior history remains |

No Identity duplication or precedence rule is introduced.
