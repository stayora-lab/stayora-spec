# Sale-assisted Request capability

Before Sale may create a Request, the canonical B1 prerequisites are: a resolved Sale Identity/capacity, valid Sale eligibility, a relevant active Distribution Relationship/scope where required, supply visible under policy, current derived Availability/Bookability information, sufficient Guest intent and a valid Request path.

The capability is:

```text
Sale discovers → prepares/shares option → captures Guest intent → creates Booking Request
→ Host / delegated Booking Authority decides
```

Sale does not accept, reject or confirm a Request merely because it created it. A Request does not reserve Inventory. Acceptance, Temporary Inventory Commitment, Required Payment Condition and Booking Confirmation remain B1/CP4 semantics. Offer/quote ownership, minimum Request data and notification timing remain TBD.
