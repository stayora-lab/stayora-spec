# Sale Working Context activation

Sale context becomes useful when an Identity is resolved, Sale capacity is recognized, required eligibility is valid, a relevant Distribution Relationship is active and resource/market scope is available. This is a projection/outcome, not a universal `SALE_ACTIVE` state.

The context may project eligible supply, public/approved commercial information, Requests, relevant Booking outcomes and attributable activity. Each action still resolves capability, resource scope, lifecycle and policy. Context usability does not grant Booking Authority, Inventory Authority, Host authority, financial visibility or Stay operations authority.

If eligibility is pending, relationship is missing, scope is empty or policy blocks a transaction, the context may remain partial or unavailable while the underlying Identity and history remain intact.
