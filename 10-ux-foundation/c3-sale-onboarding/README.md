## Protected distinctions

`Identity ≠ Party ≠ Sale capacity ≠ Sale eligibility ≠ Distribution Relationship ≠ resource scope ≠ attribution ≠ Booking Authority`. Sale Working Context is a projection, not permission. Sale may create a Booking Request within scope, but cannot accept it merely because it created it. Sale attribution is not authority, commission entitlement, Settlement or Payout. Sale does not automatically gain Host, Inventory or Stay-operations authority.
