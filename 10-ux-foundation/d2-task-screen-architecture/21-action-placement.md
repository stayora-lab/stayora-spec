# Action Placement Architecture

| Consequential action | Structural home | Canonical effect | Required authority | Later interaction work |
|---|---|---|---|---|
| Accept/reject Request | HST-04 | Booking Request decision; possible finite payment/commitment effect | Host/authorized Co-host | Action flow placeholder only |
| Record External Accommodation | HST-08 | External Accommodation fact and Inventory/Stay relationship | Authorized recorder | Manual-assisted entry may be needed |
| Create Owner/maintenance block | HST-09 | Inventory Commitment/Block | Explicit Inventory/consequence authority | Policy-dependent |
| Check-in | BUT-03 | Stay operational milestone | Authorized Butler/operations actor | Field flow later |
| Checkout | BUT-05 | Stay completion evidence/milestone | Authorized operations actor | Field flow later |
| Report Incident | BUT-04 | Incident/evidence | Operational actor | Evidence/consent policy TBD |
| Assign Butler | HST-11 / ADM-01 | Butler Assignment relationship | Host/Admin according to canonical authority | Relationship UI later |
| Property publication action | HST-02 / ADM-02 | Property representation outcome | Canonical publication/verification authority | Policy boundary remains |

Screen architecture exposes the structural entry. It does not decide controls, confirmation, form fields, loading behavior or microcopy.
