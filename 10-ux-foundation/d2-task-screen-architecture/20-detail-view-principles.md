# Detail View Principles

A canonical object earns a detail concept only when a user must understand current truth, context/history, make a consequential action, coordinate a handoff or inspect an exception. This justifies Request Detail, Booking Detail, Stay Detail, Incident/Exception detail and scoped accommodation detail. It does not justify a detail page for every CP7 entity.

Detail concepts may combine related projections, but they must not merge object semantics: Request remains separate from Booking; Booking from Stay; External Accommodation from Stayora Booking; Incident from Maintenance Block; Payment from Entitlement/Settlement/Payout.
