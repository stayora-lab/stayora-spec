# Home / Today Decisions

| Surface | Decision | Reason |
|---|---|---|
| Public Marketplace | No private Home; discovery is the entry structure | Public discovery task is primary |
| Guest Stay Access | Stay Hub is justified; generic dashboard is not | One scoped Stay truth is the central job |
| Host | Responsibility Overview justified | Host needs current requests, stays, conflicts and property responsibility |
| Sale | Activity/Outcome projection justified; generic dashboard not required | V0 centers supply discovery and Requests |
| Butler | Today & Assignments justified | Field operations and assigned responsibility are time-sensitive |
| Destination/BQL | Operations Today justified | Arrivals, departures and active stays are destination-scoped |
| Admin | Attention/governance collection justified | Admin is exception/manual-assist oriented |

These are structural concepts, not final navigation labels or dashboard layouts.
