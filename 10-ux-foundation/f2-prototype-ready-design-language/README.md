## Status vocabulary

- **ACCEPTED FROM F1:** already established foundation or semantic boundary.
- **ADAPTED FROM GROK:** candidate composition or visual character made compatible with CP8.
- **ACCEPTED — F2 FOUNDER DECISION:** visual direction accepted for the CP8-G baseline.
- **TBD:** intentionally unresolved; a prototype must use a labelled placeholder.
- **REJECTED:** a visual or semantic convention that conflicts with CP8 and must not reappear in CP8-G.

The seven surfaces remain exactly: Public Marketplace, Guest Stay Access, Host Workspace, Sale Workspace, Operations — Butler, Operations — Destination/BQL and Stayora Admin. Owner remains a perspective/context inside Host/Property architecture.

## Stop condition

F2 stops at prototype-ready documentation. It does not create React/Tailwind code, a token file, a Figma library or production UI. The final status is **F2: ACCEPTED**, **CP8-F: COMPLETE / ACCEPTED**, **CP8-G: READY FOR FOUNDER / PRODUCT ARCHITECT VALIDATION**. The [final reconciliation & closure report](CP8-F2-FINAL-RECONCILIATION-CLOSURE-REPORT.md) is the current closure record; the earlier completion report is retained as historical pre-closure context.
