## C. Visual direction

F2 proposes a warm hospitality direction: cream canvas, light surfaces, warm ink, restrained purple action, calm imagery, simple card/list composition, tabular numerals and calm motion. Values are marked ADAPTED FROM GROK / PROPOSED, not accepted. Public, Guest, workspace, operations and Admin profiles share a system while varying density and emphasis.

## D. Token system

F2 translates F1's reference → semantic → component/pattern architecture into candidate reference values and prototype-ready semantic families for surfaces, text, borders, actions, interaction states and all required outcomes. Preliminary contrast checks are evidence only; full review remains open. UNKNOWN, PENDING and CONFLICT remain distinct from FAILED, SUCCESS and winner semantics.

Plus Jakarta Sans is the leading product/workspace candidate; Cormorant Garamond is a selective display/editorial candidate. Roles cover display, page title, section heading, object title, body, compact body, label, metadata and numeric/tabular. Exact font availability, licensing and scale remain TBD.
