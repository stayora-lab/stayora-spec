# B1–B5 compatibility

| Baseline | C2 compatibility result |
|---|---|
| B1 Sale-assisted Booking | Establishes explicit Host/Booking Authority prerequisites without giving Sale acceptance or Inventory authority. |
| B2 External Booking → Stay | Supports authorized External Accommodation recording and Stay context without fabricating a Stayora Booking. |
| B3 Direct Guest Booking | Supports discovery/Request prerequisites without changing Request, Booking or Guest-without-account semantics. |
| B4 Stay Operations | Supplies Property/Unit/Destination and responsibility context without making Booking the operational source of truth. |
| B5 Inventory Intervention | Requires explicit Inventory responsibility/capability; Owner relationship alone does not control Inventory. |

No accepted journey is changed. C2 only documents upstream prerequisites and unresolved dependencies for onboarding.
