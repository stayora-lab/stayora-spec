# C2 Overview

**Known truth.** CP8-C1 supplies the shared sequence `Identity → Party/capacity → relationship → resource scope → eligibility/assignment → explicit authority → Working Context → bounded action`. CP2–CP7 and CP8-B1–B5 define the relevant domain and authority boundaries.

**C2 purpose.** Apply that sequence to two V0 onboarding orientations:

- **Actor-first:** an Owner/Host-intending actor begins, then identifies or creates a Property relationship.
- **Resource-first:** a Property is represented first, then Owner/Host relationships are established.

Both are valid entry orientations. Neither is a universal lifecycle or a permission shortcut. The output is a set of independent truths and readiness projections, not `PROPERTY_ONBOARDING_COMPLETE`.

**Out of scope.** Legal ownership adjudication, evidence thresholds, enterprise organizations, Managed Operations contracting, Sale or Butler detailed onboarding, screens/forms, technical invitation mechanisms, persistence and new authority/state concepts.

**Decision status.** C2 is documentation in draft review. Unknown policies stay `TBD`; a claim is never silently promoted to a relationship.
