# Convergence model

Actor-first and resource-first are orientations, not competing domain models. They must converge on the same canonical record of:

1. Identity, Account and Party/capacity;
2. Property and Destination relationship;
3. Bookable Unit representation;
4. Owner, Primary Host and delegated Co-host relationships;
5. evidence/basis and provenance for each relationship;
6. platform eligibility, explicit authority capability and resource scope;
7. Working Context projection;
8. independent readiness outcomes.

The convergence rule is **same truth, different entry point**. A person entering through a Property must not receive a different Owner/Host meaning from a person entering through a Host context. A claim, invitation, existing association and Admin-assisted path can supply different bases, but the established relationship and authority semantics remain common.

The model never collapses `Owner → Host → Booking/Inventory/Finance`. Every privileged action still resolves acting Identity, capacity, capability, resource scope, lifecycle and policy.
