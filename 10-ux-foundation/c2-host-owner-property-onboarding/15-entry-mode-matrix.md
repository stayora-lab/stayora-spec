# Entry-mode matrix

| Mode | Initiator / subject | Intended relationship | Basis | Pending / failure boundary |
|---|---|---|---|---|
| Owner self-entry | Owner-intending Identity / Property | Owner claim or relationship | Claim plus later basis | Claim is not truth; evidence policy TBD |
| Host self-entry | Host-intending Identity / Property | Primary Host or Co-host proposal | Existing association, designation or invitation | Owner/Host separation and authority remain explicit |
| Owner invitation | Existing authorized context / invited Identity | Owner relationship | Invitation and acceptance plus relationship decision | Invitation is not relationship |
| Host invitation | Existing authorized context / invited Identity | Host relationship | Invitation and acceptance plus scope decision | No automatic Booking/Inventory authority |
| Admin-assisted Property setup | Stayora Admin / Property | Representation, later relationships | Admin function and provenance | Admin is not Owner/Host; authority must be explicit |
| Property-first setup | Resource initiator / Property | Property, Destination, Unit representation | Resource identity and provenance | Creator gains no relationship/authority shortcut |
| Actor-first setup | Identity / Property candidate | Owner/Host relationship | Identity/Party/capacity and later basis | Property may remain pending |
| Existing Property claim | Claimant / existing Property | Proposed relationship | Claim and conflict evidence | Preserve claims; no winner chosen |
| Existing Identity linkage | Existing Identity / Party | Capacity or resource relationship | Existing canonical association | Matching/merge policy TBD |

No row defines a technical invite, legal proof, field set or universal completion state.
