# Property, Destination and Bookable Unit

`Destination → Property → Bookable Unit` remains the conceptual resource relationship. Property is the accommodation representation; a Bookable Unit is the resource that can be committed for a time range. Inventory belongs to Unit × Time.

Minimum conceptual representation is limited to the truths already supported by CP7: Property identity/physical-business representation, Destination membership, one or more Bookable Unit relationships where applicable, Owner/Host relationships, publication readiness, Inventory responsibility and Verification relationship where applicable. C2 does not define fields or unit types.

For Oceanami V0, the CP7 conceptual example of one Villa as one Property plus one Entire-Villa Unit remains an example, not a universal onboarding requirement. A Property may exist before Unit truth is sufficient for Inventory or Booking.

Destination membership identifies operational context. It does not grant BQL authority, Host authority, Booking Authority, Inventory Authority, Owner authority or commercial authority.
