# C1 compatibility

C2 preserves the C1 chain:

`Identity → Party/capacity → relationship → resource relationship → eligibility/assignment → explicit authority/scope → Working Context → bounded action`.

Compatibility checks passed conceptually:

- no role-based permission shortcut;
- no Property-creator Owner/Host shortcut;
- no Owner-to-Booking/Inventory/finance shortcut;
- no global onboarding state;
- invitations and claims remain proposals/bases, not truth;
- Working Context remains a projection, not permission.

C2 specializes C1 for Property/Owner/Host and does not alter C1's Sale/Butler architecture. Any unresolved identity matching, evidence, authority grant or privacy rule remains in [C1 TBD register](../c1-onboarding-architecture/22-tbd-policy-register.md).
