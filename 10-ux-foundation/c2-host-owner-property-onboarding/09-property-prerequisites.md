# Property representation prerequisites

| Outcome | Required conceptual truth | Not required by C2 unless another canonical rule says so |
|---|---|---|
| Property represented | Property identity/representation; provenance; candidate Destination/Unit links where known | Owner, Host, publication, Verification, Managed |
| Relationship-complete context | Established relationship(s) and scope for the intended actor/resource context | All possible roles or financial truth |
| Publication-eligible | Canonical Property Authority and applicable publication conditions | Verification unless a policy requires it |
| Inventory-ready | Unit × Time representation, Inventory responsibility and explicit Inventory Authority | Owner automatically controlling Inventory |
| Booking-ready | Published/searchable where relevant, Inventory truth, Booking Authority and commercial eligibility where canonical | A new Booking solely from onboarding |
| Stay-operations-ready | Property/Unit, Destination context and operational responsibility/assignment as applicable | Butler onboarding or a Booking as the only source of Stay truth |
| Verified | Separate Verification relationship/status where a program applies | Publication or Managed by default |
| Managed | Separate contractual/operational model | Current V0 core |

These are outcomes/projections and eligibility conditions, not new Property lifecycle states. There is no universal `PROPERTY_ONBOARDING_COMPLETE`.
