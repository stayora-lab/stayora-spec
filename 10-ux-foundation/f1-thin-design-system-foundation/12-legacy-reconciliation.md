# F1. Legacy visual reconciliation

A repository scan found no separate canonical Stayora visual token, typography, component-library or brand artifact. The CP8-A–E documents are the current behavioral/semantic source; existing historical product material remains reference unless explicitly adopted.

| Classification | Current treatment |
|---|---|
| **KEEP** | CP8-A–E semantic language, seven surfaces, Working Context, shared truth/contextual projections, authority visibility, interaction outcomes and accessibility boundaries. These are architecture inputs, not legacy styling. |
| **ADAPT** | Any later legacy visual primitive that can meet the F1 semantic, accessibility and composition rules. Reuse requires an evidence-based mapping to semantic tokens and no conflict with CP8. |
| **DEPRECATE** | Legacy color/state conventions that collapse UNKNOWN into FAILED, Pending into Success, Conflict into a winner, or encode domain objects as permanent colors; any Owner top-level workspace assumption; any visual convention that implies presence equals authority. |
| **UNDECIDED** | Unverified fonts, palette values, existing component APIs, spacing/radius/elevation recipes, dark mode, chart/calendar styling and external brand references. No replacement is selected in F1. |

Legacy behavior must not override CP8 source-of-truth. If a future artifact is discovered, classify it against this table before adopting or replacing it.
