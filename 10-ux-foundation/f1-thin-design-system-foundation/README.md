## Protected inputs

F1 derives from [CP8-A](../README.md), CP8-B1–B5, CP8-C1–C4, CP8-D1–D3 and the [CP8-E Detailed Interaction baseline](../../11-detailed-interaction/README.md), including the [Founder Decision Reconciliation](../../11-detailed-interaction/CP8-E-FOUNDER-DECISION-RECONCILIATION.md) and [Closure Coverage report](../../11-detailed-interaction/CP8-E-SOURCE-OF-TRUTH-BATCH-RECONCILIATION-REPORT.md). Those sources remain authoritative for product, domain, authority, lifecycle, policy and interaction semantics.

The system supports exactly these seven surface families:

1. Public Marketplace
2. Guest Stay Access
3. Host Workspace
4. Sale Workspace
5. Operations — Butler
6. Operations — Destination/BQL
7. Stayora Admin

Owner is a perspective/context inside Host/Property architecture, not a new top-level workspace.
