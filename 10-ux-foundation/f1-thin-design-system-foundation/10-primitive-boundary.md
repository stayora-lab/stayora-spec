# F1. Primitive boundary

This is a bounded inventory for later prototype work, not approval to build every item.

| Classification | Primitive families | Reason |
|---|---|---|
| **CORE** | Button/action; Link; Field/form structure; Input/Textarea; Alert/Callout; Status/Badge; Card/Panel; Dialog; Sheet/Drawer; Loading/Skeleton; Empty state; Error/feedback; Table/List foundation | Recur across all seven surfaces or are required to show authority, truth, outcome and accessible structure. |
| **LIKELY** | Select/Combobox; Checkbox/Radio/Switch where a real choice requires it; Popover; Tabs; Menu; Avatar/identity marker; Toast/feedback; Date/calendar primitives | Expected in CP8-G journeys, but the prototype should prove the exact composition and not pre-build a complete library. |
| **DEFER** | Command palette; rich editor; charting; drag-and-drop board; advanced data grid; upload manager; notification center; complex date-range picker; generic task system; universal timeline | Build only if a later accepted prototype need demonstrates it. None is required to establish F1. |

All classifications are subject to accessibility and journey evidence. A primitive may be implemented with shadcn/ui/Radix-style foundations later, but F1 does not create React, Tailwind or CSS artifacts.
