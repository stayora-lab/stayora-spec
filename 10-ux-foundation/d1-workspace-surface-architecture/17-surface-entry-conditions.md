# Surface entry conditions

| Surface | Conceptual entry condition |
|---|---|
| Public Marketplace | Public request/discovery; no authenticated relationship necessarily required |
| Guest Stay Access | Valid scoped Guest/Stay/access basis; account optional where canonical |
| Host Workspace | Valid Owner/Host/Co-host/Property relationship and relevant scope/authority |
| Sale Workspace | Sale eligibility + active Distribution Relationship + resource/market scope where required |
| Butler Context | Butler eligibility + active Assignment + resource/function scope |
| Destination/BQL | Destination Staff relationship + destination/function scope |
| Stayora Admin | Explicit platform staff function/domain/resource authority |

Entry conditions are conceptual. They do not define authentication, tokens, routes or UI gates.
