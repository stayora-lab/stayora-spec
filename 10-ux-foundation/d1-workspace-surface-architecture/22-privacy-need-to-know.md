# Privacy and need-to-know

| Classification | Typical surfaces |
|---|---|
| PUBLIC | Public Marketplace; public listing/price/trust signals |
| RELATIONSHIP-SCOPED | Owner/Host/Sale relationship projections |
| RESOURCE-SCOPED | Property, Unit, Request, Booking, Stay, Assignment |
| OPERATIONAL NEED-TO-KNOW | Butler/BQL/Host/Guest operational data |
| COMMERCIAL NEED-TO-KNOW | Sale/Host/Owner/Money projections |
| ADMIN / EXCEPTION-SCOPED | Admin cases, audit, reconciliation evidence |
| PRIVATE / NOT VISIBLE | Unrelated Guest data, private authority/evidence, full ledgers and unrelated resources |

These are architecture categories, not exact field-level rules. QR/access, Guest linkage, retention, consent and field visibility remain policy/TBD.
