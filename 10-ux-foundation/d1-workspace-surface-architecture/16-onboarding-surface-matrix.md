# Onboarding × Surface matrix

| Outcome | Context availability / projection | Boundary |
|---|---|---|
| Identity only, no relationship | Public may remain available; no private actor surface by default | Identity does not create capacity/authority |
| Owner relationship, no Host authority | Host/Property partial context for scoped Owner facts | No Booking/Inventory actions without authority |
| Property represented, unpublished | Host/Admin relationship context | Public Marketplace does not show it |
| Sale eligible, no Distribution Relationship | Sale capacity/eligibility projection only | No supply scope or Request action |
| Sale relationship active, limited scope | Sale context shows scoped supply/actions | Not all supply visible/bookable |
| Butler eligible, unassigned | Eligibility/Admin projection only | No Butler operational context |
| Butler assigned | Butler Property/Stay/function projection | Assignment does not grant other-domain authority |
| BQL relationship/function | Destination operational context | No Owner/Host/Booking/Inventory authority |
| Guest access basis valid | Guest Stay Access | No full registered-account workspace required |

These outcomes are projections, not universal onboarding states.
