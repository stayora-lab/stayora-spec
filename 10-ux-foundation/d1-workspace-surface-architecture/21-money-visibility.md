# Money visibility boundary

| Surface | Contextual visibility |
|---|---|
| Guest | Own applicable payment requirement, transaction/confirmation and relevant refund/status information |
| Host/Owner | Own authorized economics, Booking Value/entitlement/Settlement projections only within financial scope |
| Sale | Sale-relevant commercial/attribution/earnings projection where policy supports it |
| Butler/BQL | Normally no unrelated payment, Owner/Sale economics, Settlement or Payout |
| Admin | Functionally required exception/reconciliation information with reason and audit |
| Public | Public Price only; no private economics |

Attribution ≠ Commission Entitlement ≠ Settlement ≠ Payout. C3's confirmed 10% Sale base commission and all unresolved CBV/economic policy remain unchanged; D1 does not infer values across contexts.
