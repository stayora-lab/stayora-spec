# Owner perspective analysis

CP6 does not establish a separate top-level Owner Workspace. D1 therefore treats Owner as a capacity/perspective within the Host/Property context where a valid ownership relationship and scope exist, while keeping Owner and Primary Host distinct.

Owner may need Property/supply facts, relevant Requests/Bookings/Stays, quality and own scoped economics. Host may need operational/commercial responsibility, delegation, Inventory and Booking actions. Their overlap is contextual; financial visibility, publication, Booking, Inventory and delegation remain authority-dependent.

An Owner without Hosting/Booking/Inventory authority receives a partial context and cannot be given a dashboard shortcut. A separate Owner surface is an **IA/UX gap** if later requirements prove a distinct responsibility set is needed; D1 does not create one.
