# Assignment architecture

Butler Assignment is a relationship that connects an eligible Butler Identity to a supported resource/function scope for a period of validity. It should conceptually preserve assigner/source, assignee, resource, function, effective validity, responsibilities, information projection, action capability where separately granted, revocation and audit provenance.

Supported scope is only what existing architecture supports: Destination/function scope for Destination Staff, Property responsibility, and Stay-related operational scope. Bookable Unit or time-range granularity may be used only where the canonical workflow establishes it; C4 does not create a universal hierarchy. Assignment is not Authority, commercial relationship, Booking Authority, Inventory Authority, financial authority or consequence authority.

Assignment can be active, pending, ended, revoked or corrected as relationship outcomes under policy, without creating a new universal Butler state machine.
