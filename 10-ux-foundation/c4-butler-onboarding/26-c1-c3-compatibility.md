# C1–C3 compatibility

C4 preserves the shared onboarding chain:

`Identity → capacity/relationship → eligibility → Assignment/resource scope → explicit action authority → Working Context → bounded action`.

It does not modify C2 Owner/Host/Property truth or C3 Sale truth. Butler Assignment is not an Ownership, Hosting, Distribution Relationship or authority shortcut. A multi-capacity Identity keeps independent Butler, Host, Owner or Sale contexts and audit bases. Working Context remains a projection, and there is no universal Butler onboarding state.
