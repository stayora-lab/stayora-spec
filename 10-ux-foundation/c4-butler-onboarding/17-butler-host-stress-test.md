# Butler + Host stress test

Identity A may hold Butler Assignment and a Host relationship/authority. A may record an Incident as Butler, then perform a separate authorized Host action under the Host capacity and authority basis. The audit records the actual acting capacity and source for each action.

Butler Assignment does not create Host Authority; Host Authority does not erase Butler Assignment. If Host authority ends, Butler context can remain only to the extent its Assignment/eligibility and operational policy remain valid.
