# Entry Paths

Accepted structural entry modes are public discovery, responsibility destination, attention projection, scoped Guest access, contextual deep link, cross-surface handoff and context/resource selection. Examples:

- Public discovery → Property/Unit → date intent → Request entry.
- Sale supply → option → Request entry → Host Requests.
- Host attention → Request/Inventory/Stay detail → action or handoff.
- Booking/External Accommodation → Guest Stay Hub and operations.
- Butler/BQL Today → assigned Stay/Incident/service context.
- Onboarding outcome → partial or activated context only when relationship/eligibility exists.

No URL, notification implementation or redirect into unauthorized context is specified.
