# Sale Workspace Convergence

**Primary destinations:** `SAL-01 Supply Discovery` and `SAL-04 Sale Activity & Outcome`.

`SAL-02 Option & Offer Context` is contextual object preparation from supply; `SAL-03 Request Entry` is an action entry; `SAL-05 Attribution & Earnings Summary` is a permitted contextual projection; `SAL-06 Sale Exception` is embedded attention from activity. No generic Sales Dashboard, CRM, pipeline, commission engine or Affiliate Network is created.

Sale remains a distribution context with eligibility + active Distribution Relationship + scope. It can initiate a Request but cannot accept Booking Requests, mutate Inventory or operate a Stay.
