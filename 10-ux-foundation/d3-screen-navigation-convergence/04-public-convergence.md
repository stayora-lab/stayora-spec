# Public Marketplace Convergence

**Primary destination:** `PUB-01 Destination Discovery` as the public discovery entry.

`PUB-02 Destination Detail` is a contextual destination/detail reached from discovery. `PUB-03 Accommodation Detail` is a Property/Unit object detail reached from Destination/discovery. `PUB-04 Date & Availability Intent` is contextual resource selection embedded in the accommodation intent path. `PUB-05 Request Entry` is an action entry/flow placeholder, not a navigation destination.

Destination, Property and Unit remain distinct. Public structure preserves Searchability ≠ Availability ≠ Bookability. No checkout, private economics, operational notes or authority is introduced.
