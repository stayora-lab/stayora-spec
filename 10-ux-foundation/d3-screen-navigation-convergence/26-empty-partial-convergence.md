# Empty / Partial Context Convergence

`NO DATA` appears inside a valid responsibility destination; `NO RELATIONSHIP` keeps a group unavailable or partial; `NO SCOPE` prevents unrelated resources from entering global projections; `NO AUTHORITY` allows visibility only where canonical and removes action entry; `PENDING` keeps onboarding/verification/publication outcomes explicit; `CONFLICT / EXCEPTION` enters the appropriate attention projection; `OUT OF SCOPE` is not represented as fake navigation content. No default Property, Stay, Request or financial record is fabricated.
