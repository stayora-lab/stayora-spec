# Context / Resource Switching

`Identity → Working Context → Resource Scope → Responsibility Destination → Object Detail → Action`.

- **Context switch:** Host → Sale changes responsibility groups and allowed projections; it does not grant permission.
- **Resource switch:** Property A → Property B inside Host changes Property/Unit/Request/Stay projections; it does not grant authority over B.
- **Destination switch:** BQL Destination A → Destination B changes destination scope only.
- **Assignment switch:** Butler Today can move between valid Assignments; an Assignment is required for operational scope.
- **Stay-scoped entry:** Guest deep/scoped access opens the represented Stay without exposing a global Guest workspace.

Every action re-evaluates effective CP3 authority, relationship validity, resource scope, state and policy. A selected context/resource is not itself a permission grant.
