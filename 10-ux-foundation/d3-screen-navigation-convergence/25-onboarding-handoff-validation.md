# Onboarding Handoff Validation

| Outcome | Context/destination | Partial condition | Unavailable actions | Legitimate handoff |
|---|---|---|---|---|
| Identity only | no private context | no relationship/eligibility | all resource actions | ADM-01 if application exists |
| Owner relationship/no Host authority | scoped HST-02 projection | no Host authority | Request/Inventory decisions | authority establishment |
| Host + Property scope | Host context + HST-01/02 | unpublished/incomplete if applicable | publication/commerce until outcome | Public after canonical publication |
| Sale eligible/no Distribution Relationship | Sale application/ADM-01 | no supply scope | discovery/Request | active relationship → SAL-01 |
| Sale active relationship | Sale + SAL-01/04 | scope-limited | Booking/Inventory mutation | Host Request handoff |
| Butler eligible/unassigned | no operational Today | unassigned | Check-in/Checkout/Incident action | Assignment → BUT-01 |
| Butler assigned | Butler + BUT-01 | assignment scope | out-of-scope Stays/Inventory | Host/BQL/Guest ops handoff |
| Multi-capacity Identity | selectable contexts | each context/resource scope | actions outside active authority | explicit context switch |

Navigation never manufactures a context to avoid a partial state.
