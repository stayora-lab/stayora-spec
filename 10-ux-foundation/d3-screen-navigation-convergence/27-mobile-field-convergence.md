# Mobile / Field Convergence

Guest Stay Hub/Access and Sale supply/request remain shallow and mobile-important. Butler Today → assigned Stay → action entry and BQL Today → Stay/Incident/service context are field-critical, with no need for every step to be a navigation item. Host has responsibility destinations with desktop-important collections and operational mobile entry. Admin governance/audit is desktop-important. Public discovery is device-neutral. No native app, breakpoint or responsive layout is defined.
