# CP8-D3 — Screen & Navigation Convergence

> Parent: **CP8 — UX / Design System** → **CP8-D Workspace / Surface UX**
> Status: **ACCEPTED AS BASELINE FOR CP8-E1**
> Freeze status: **NOT FROZEN** · Scope: **D3 baseline for E1** · 2026-09-21

D3 is the final convergence pass inside CP8-D. It classifies every D2 screen concept as a primary destination, contextual destination/detail, embedded projection, action entry/flow, scoped access view or removed concept; then derives responsibility groups and conceptual navigation inputs. It is the accepted baseline for [CP8-E1 Interaction Model & Behavioral Conventions](../../11-detailed-interaction/e1-interaction-model-behavioral-conventions/README.md). It does not finalize visual navigation, routes, layouts, interaction details, design system or implementation.
