# Screen Economy Review

D3 does not optimize for a raw screen count. It reduces navigation destinations by grouping responsibility while preserving the 42 D2 concepts as details, projections or action entries. No D2 concept is removed: concepts become primary, secondary/contextual, detail, embedded, action, attention or scoped access. Shared composition is allowed only when canonical objects remain distinct.

The main convergence is Host: 12 references become a small set of responsibility groups rather than 12 navigation items. Guest becomes a Stay-centered access structure; Butler and BQL become field-centered Today structures; Admin becomes governance/exception centered. Public and Sale retain discovery and activity responsibilities without OTA/CRM expansion.
