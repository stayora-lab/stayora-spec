# Critical Journeys

> Status: **STABLE — CHECKPOINT 5 DOCUMENTED; NOT FOUNDER FREEZE**

## Sale-assisted booking — MUST BUILD

Guest contacts Sale externally → Sale searches actual Availability and Public Price → quote/discussion → Sale creates Booking Request → Host/authorized Co-host accepts or rejects → finite authorization and Temporary Exclusive Commitment where applicable → Required Payment Condition and evidence → Booking CONFIRMED → Confirmed Accommodation Commitment → need-to-know Butler/BQL data → Guest confirmation and scoped QR/link → arrival/check-in → Stay → checkout → Operational Completion Readiness → Stay COMPLETED → economic reconciliation.

Request does not reserve inventory. Phone approval does not replace system acceptance. Sale cannot accept for Host without delegated authority. Direct and Sale paths converge on the same Booking, Inventory and Stay truth.

## External booking to Stay — MUST BUILD

External Commerce → external booking/stay registration → Confirmed Accommodation Commitment → Stay Operations → QR/access where applicable → Check-in → Stay → Checkout → completion. Airbnb, Booking.com, Zalo, Owner Direct and other evidenced sources are valid. Do not create a fake Stayora Booking, require external price/revenue/payment details without an independently supported need, or create automatic commission. Conflicts must be detected/surfaced; automated resolution is not required.

## Direct Guest booking — MUST BUILD

Destination discovery → listing/property → dates/Availability → Public Price and trust signals → Request to Book → Host acceptance → applicable commitment and Required Payment Condition → Booking CONFIRMED → scoped access → Stay Operations. Guest account is not mandatory merely to access a paid Stay. Instant Book remains supported by architecture but is optional/controlled pilot capability, not a V0 MUST.

## Availability control — MUST BUILD

Availability derives from Confirmed and Temporary Commitments, external commitments, Owner Blocks and authorized maintenance/operational Blocks. Butler may report an operational problem but does not receive commercial inventory authority merely by operating a villa. Full maintenance/work-order tooling is deferred.

## Incident/exception — MANUAL-ASSISTED

Record → assign/handle → evidence → assess → resolve → audit. Complaint/Observation ≠ Incident ≠ Finding ≠ Responsibility ≠ Consequence. Complex refunds, compensation, Verification review and reputation consequences may be manually assisted; historical transactions remain intact through adjustment/refund/reversal events.
